CSS Background Styling

Introduction

CSS background properties are used to improve the appearanceof a webpage. We can apply background colour, background images and control how the image is displayed using different CSS properties.

Background properties Used

  • background-color
  • background-image
  • background-repeat
  • background-position
  • background-attachment

Advantages

Background Styling improves the visual appearance of webpage and make content more attractive and readable.
